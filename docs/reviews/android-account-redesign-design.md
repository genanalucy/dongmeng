# Android「我的」改版设计

状态：用户已授权实现；遵循此前问答结论，其余细节由实现方决定。

## 目标与范围

首屏三秒内说明账户的翻译权益是否可用。采用极简工业风、硬件伴侣式信息层级，沿用当前品牌颜色。深色与浅色共用组件、布局和交互，仅颜色随系统变化。不修改生产管理后台、不改 Room schema、不清 App 数据。

## 页面树

- 我的：首页身份、权益摘要、历史/权益/账户/安全四项纵向入口。
- 权益详情：完整权益状态、到期时间、累计使用量、兑换入口。
- 兑换：独立输入页面，真实 API、加载防重、成功与失败反馈。
- 账户：现有真实资料、可用的偏好设置入口、底部注销危险区。
- 安全：真实设备/会话信息及退出登录。必须准确标注 API 的业务语义；翻译会话终止不等同于设备退出登录。

主层保留「对话／同传／我的」；二级页顶部返回及系统返回，隐藏主层底部导航。

## 首页

1. 品牌符号、用户名、账户类型。不显示邮箱，不伪造头像。
2. 权益大卡：类型、有效状态、大号剩余天数、精确到期日期。整卡进入详情；不足一天显示「不足 1 天」，不错误显示为过期。
3. 无有效权益时为中性灰卡，提升兑换按钮。浅色采用黑色主按钮，深色用高对比反色，禁止黑底黑字。
4. 四个纵向入口。历史只显示标题和功能说明，无假数量或记录摘要。首页不展示累计用量、不常驻兑换输入、不放退出登录按钮。

## 状态规则

- 初次读取：稳定结构、局部加载，不阻断本地历史。
- 网络错误：顶部轻提示、权益卡「暂不可确认」及重试；不能展示「暂无权益」代替错误。
- 已知有效权益：正常摘要。
- 已知过期或空权益：明确状态及兑换按钮。
- 兑换成功但概览刷新失败：兑换仍成功，清空输入，不诱导再次兑换；详情注明待刷新。
- 会话失效：保留既有清理和登录恢复行为，不被旧兑换成功提示遮挡。

## 主题与无障碍

使用 MaterialTheme.colorScheme 语义色，成对配置容器与文字。保留现有深色品牌方向，浅色不另建布局。不得借主题改动重做对话/同传结构。最小触控区域48dp、可滚动长页面、支持大字体、错误不只靠颜色表达、装饰图标不重复朗读。

## 真实能力边界

首页不做耳机连接卡，不显示未经检测的设备状态。安全页由实际 API 数据决定可用操作；无单设备登录撤销 API 时不添加假按钮，也不把翻译会话撤销命名为退出设备。开发连接配置维持 debug 限制，Release 端点不可编辑。不新增购买、头像上传或普通用户改密码能力。

## 验证

- 状态映射：加载、错误、有效、过期、空权益、不足一天。
- 导航：四个入口可达、兑换独立、返回正确、退出在安全页。
- 深浅主题：同一组件结构、可读文字/容器配色。
- 保留兑换 API、授权恢复、部分成功与错误优先级回归覆盖。
- Android 单测、lint、Debug/Release/AndroidTest 构建。
- 仪器测试运行、深浅截图和真机验收须单独说明，构建不替代实际设备验证。
