## 范围与安全边界

- 基于 GitHub `main` 的 `f26d690`，本阶段仅 Debug versionCode 从 21 升至 22，未修复业务逻辑，不改变 Release versionCode、地址或 OTA。
- 不发布 GitHub Release，不部署服务；不卸载、清除 App 数据或强制降级。安装前检查设备已安装版本、签名与包名。
- 不自动退出当前用户：退出会清除本机历史副本。登录回归使用专用测试账号，先确认历史已保存/同步及测试账号可用。账号密码仅由用户在手机输入。
- 真实翻译会消耗额度、占用麦克风；30 分钟测试须用户再次确认。只用公开测试短句，不采集私人对话，不保存原始音频、密码、token 或用户历史。
- 默认 Debug 与正式入口不同，且 Debug 本地设置可能覆盖默认值。必须记录实际入口，不能由健康检查推断登录/翻译通过。
