# Android Core Translation UI Redesign — 验收清单

## 安全记录规则

- 仅记录通过/未通过及可复现的界面行为。
- 不记录 token、DSN、URL、header、原始日志或会话 ID。

## 手工验收

- [ ] 默认进入“面对面翻译”；底部栏有“面对面 / 同传 / 我的”，当前项清晰可辨。
- [ ] 手动模式：分别长按左、右麦克风；对应方向进入收音状态并显示波纹；按住期间不得提前 release，真实松开和系统取消各只触发一次 release。
- [ ] 自动模式：左侧持续收音；长按右侧时收音与波纹转至右侧；松开或取消后恰好一次回到左侧。
- [ ] TalkBack、Switch Access 和键盘触发左右麦克风时，无障碍语义 action 不得与指针事件重复触发 press/release。
- [ ] 麦克风权限时序：按下先发起权限请求；若权限决定前松开或取消，必须使待启动请求失效，随后授权不得开始收音；拒绝绝不得开始收音；每个手势只产生一次终结 release/cleanup。
- [ ] 底部栏未被系统手势区遮挡，点击目标在安全区内可达。
- [ ] 非 idle 状态时语言选择不可打开；恢复 idle 后可选择，且两侧语言不重复。
- [ ] 同传页可开始、暂停、继续、结束；退出不会绕过麦克风权限与生命周期取消逻辑。
- [ ] 实时同传处于活动状态时，顶部仅保留紧凑的标题、状态、语言芯片和实时标记，不出现大标题区。
- [ ] 实时字幕以独立、轻量的句段气泡呈现；原文字号与对比度明显高于译文，实际字幕是页面视觉中心。
- [ ] 双语气泡仅按同一 turn 中 `sourceFinals[i]` 与 `translationFinals[i]` 的 final event 边界配对；不得先聚合、跨 event 拆句后按索引伪配，也不得以累计三个逗号作为跨 event 配对依据。
- [ ] source partial 在已有 final 后显示为独立“正在翻译…”气泡；无法安全归属的 translation partial/final 显示为无原文的独立行，不虚构语义对应。
- [ ] 有效 event pair 可整体显示，或只在可证明对应的同 event 边界细分；中文 `。`、ASCII `.` 分隔符保留在前一段。
- [ ] source-only/pending 与 translation-only 行采用显示上限：含 CJK 文本最多 42 字符、其他文本最多 90 字符；优先在范围内最后一个 `，`、`,`, 空白或换行处切分，否则硬切。所有片段拼接后必须无损还原原文。
- [ ] 多个分隔符、保留空白、以及末尾未终止文本均正确显示，且不会产生空白气泡或空白文本行。
- [ ] 底部操作区固定且不遮挡可滚动字幕；麦克风与波纹保持低调，所有可点击操作仍至少为 48dp，减少动态效果时仍有静态收音提示。
- [ ] 同传默认跟随最新字幕；在跟随状态下，新增字幕气泡或错误会自动滚动到实际末项，追加导致末项索引增加时不得被误判为用户离开而停止跟随。
- [ ] 仅用户实际手动滚离底部后暂停跟随，底部操作区上方右下角显示 48dp 向下悬浮按钮；程序自动滚动不得触发暂停；TalkBack 标签为“回到最新字幕”。
- [ ] 手动滚回底部或轻触“回到最新字幕”后恢复跟随并隐藏按钮；空字幕和仅错误状态均不发生无效滚动。
- [ ] “我的”可进入账户；认证流程、账户返回、管理员测试页与测试服务设置路由可达，且账户状态不泄露敏感信息。
- [ ] 认证账户页进入“历史”后按系统返回键，必须回到账户页而非退出应用。
- [ ] 认证账户页进入服务设置后按系统返回键，必须回到账户页而非“我的”。
- [ ] “我的”进入服务设置后按系统返回键，必须回到“我的”。
- [ ] 最小支持高度、最大字体、横竖屏下内容可滚动，关键操作仍可见可达。
- [ ] TalkBack 可读出底部栏、退出、语言、麦克风和账户操作的准确标签及状态。
- [ ] 系统减少动态效果开启时，持续收音状态仍有静态可辨识反馈。
