# Android 内部 Beta 更新手册

> 本版本仅供内部测试，不适用于生产环境。

## 下载与安装

1. 在项目的 GitHub **Releases** 页面下载最新标记为 `Pre-release` 的 `app-debug.apk`。
2. Android 首次从浏览器、文件管理器等来源安装 APK 时，按系统提示为该来源开启“允许安装未知应用”。仅授权可信来源。
3. 下载完成后打开 APK 并按系统提示安装；已有同一签名的 Debug 版本时，直接覆盖安装即可更新。
4. 如系统提示签名不一致或无法更新，先卸载旧的不兼容 Debug 版本，再重新安装。卸载会清除该应用在本机保存的数据，请先确认没有需要保留的本地数据。

## 账号与登录

注册账号需要填写：用户名、邮箱或中国大陆手机号、密码。登录时可使用上述任一已登记标识，应用会自动识别标识类型。

请使用自己可接收的邮箱或手机号完成测试；密码应为仅用于测试的独立强密码。

## Cloud 服务说明

该客户端依赖已配置的 Cloud 服务端点。内部测试环境可能调整、临时不可用或与正式环境不同；请从团队的受控渠道获取当前环境信息，不要在工单、截图或公开渠道粘贴端点地址、密钥或其他配置。

## 常见问题

- **应用启动失败或一直无法连接**：确认网络可用、安装的是最新内部 Beta；仍无法恢复时，记录发生时间和现象后联系测试负责人。
- **注册失败**：检查用户名、邮箱/手机号和密码是否按页面要求填写；确认手机号为中国大陆号码，并尝试更换未注册的标识。
- **登录失败**：确认输入的是已注册的用户名、邮箱或中国大陆手机号，以及对应密码；不要反复尝试猜测密码。
- **安装或更新失败**：确认已允许当前安装来源安装未知应用；出现签名冲突时，按上文说明卸载不兼容的旧 Debug 包后重装。

## 隐私与问题反馈

反馈问题时请附上应用版本、设备型号、Android 版本、发生时间和可复现步骤。不要提供完整手机号、密码、访问令牌、验证码或包含这些内容的截图；必要时请先打码。
