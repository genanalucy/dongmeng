# 01: 落地对话 × 手动最小闭环

**What to build:** 将已确认的极简左右对话体验接到现有手动双耳翻译闭环。用户能选择两侧语言，按住对应的独立双色麦克风说话，看到同层的流式气泡逐步成为普通历史气泡，并继续获得正确的对侧单耳译音、本机历史保存及安全错误恢复。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 对话时间线按说话方左右错位；每条气泡以原文、分隔线、译文形成清晰层级，播放目标耳语义保持正确。
- [ ] 空闲时不渲染或预留输入气泡；收音、识别及翻译时只在时间线末尾出现对应侧的临时流式气泡。
- [ ] 本轮完成后，流式气泡在原位置稳定转为普通历史气泡，不产生重复记录或明显跳层。
- [ ] 底部提供两个完整、独立、稳定双色的左右麦克风按钮；颜色之外同时以位置、耳侧和语言提供辨识。
- [ ] 两侧语言选择是靠近相应麦克风的紧凑入口，不挤占对话时间线。
- [ ] 手动模式仍是按住说话、松开提交；取消、失败、会话替换和生命周期中断不会留下错误的活跃气泡或录音状态。
- [ ] 左侧说话的译音只到右耳，右侧说话的译音只到左耳；现有历史保存所有权与次数不变。
- [ ] 覆盖空闲、收音、识别、翻译、结果、错误、长文本和大字体的单元或 Compose UI 测试。
- [ ] Android 单元测试、相关 lint 与 Debug 构建通过，不清除 App 数据，不引入迁移。
