# 05: 整合四组合并交付可验收 APK

**What to build:** 将对话／面对面与手动／连续四个组合整合成稳定产品体验，删除被替代的冗余 UI，同时保持底部产品导航、历史保存反馈、会话治理和发布端点策略。产出经过完整自动验证且可覆盖安装的 Debug APK，供真机验证双耳声道。

**Blocked by:** 01: 落地对话 × 手动最小闭环; 02: 完成对话 × 连续闭环; 03: 完成面对面 × 手动闭环; 04: 完成面对面 × 连续闭环.

**Status:** ready-for-agent

- [ ] 用户能通过克制的“视图”和“更多”入口访问四种组合，切换时活动录音和临时状态安全收束。
- [ ] 保留面对面、同传、我的三个底部产品入口；删除旧固定输入卡、方向说明卡和被新设计替代的冗余控件。
- [ ] 四组合在空闲、收音、识别、翻译、结果、错误、长文本和大字体下均无关键遮挡或错误状态。
- [ ] 所有主要触控目标达到平台尺寸要求，颜色不是唯一编码，屏幕阅读器语义准确。
- [ ] 本机历史每轮只保存一次；“已保存”只表示本机成功，不虚构云同步、耳机连接或其他状态。
- [ ] 会话替换、配额阻断、账户生命周期和 Release 固定端点行为没有回归。
- [ ] JVM 单测、lint、Debug/Release 及 AndroidTest APK 构建全部通过；若环境允许，运行 instrumentation。
- [ ] 生成新的 Debug APK 与 SHA-256；覆盖安装不清数据，并明确区分构建验证、模拟器验证和真机验证。
- [ ] 有真机和真实耳机时验证冷启动、四组合、历史详情及左说右听／右说左听；无设备时明确记录未覆盖风险。
