# 04: 完成面对面 × 连续闭环

**What to build:** 将已验证的连续双耳行为带入面对面对坐视图。远近两位用户能从自己的方向理解哪个按钮正在持续收音、如何临时接话，并在每次切换后于正确区域看到当前流式结果，同时保持正确单耳输出。

**Blocked by:** 02: 完成对话 × 连续闭环; 03: 完成面对面 × 手动闭环.

**Status:** ready-for-agent

- [ ] 面对面视图支持左侧持续收音及暂停、继续、结束。
- [ ] 右侧可从自己的阅读方向按住临时接话，松开或取消后恢复左侧。
- [ ] 流式气泡出现在正确说话方区域，完成后稳定成为历史内容。
- [ ] 上下旋转、按钮位置和颜色不会反转底层左右耳路由或保存归属。
- [ ] 无障碍语义准确描述连续模式的不对称操作，不宣称自动识别人。
- [ ] 覆盖连续开始、接话、恢复、暂停、终止、错误与生命周期切换测试。
- [ ] Android 单元测试、相关 lint 与 Debug 构建通过。
