# 03: 完成面对面 × 手动闭环

**What to build:** 用户可切换到适合桌面对坐的面对面视图，上半区域旋转给远端佩戴者阅读，下半区域供近端佩戴者使用；双方分别使用靠近自己的语言入口和双色麦克风，继续共享同一翻译状态与正确耳道语义。

**Blocked by:** 01: 落地对话 × 手动最小闭环.

**Status:** ready-for-agent

- [ ] 面对面视图由两个对向阅读区域构成，远端内容和操作旋转 180°，全局导航与视图控制保持正向。
- [ ] 两侧均复用原文、分隔线、译文及临时流式状态的视觉语言，不复制翻译业务状态机。
- [ ] 手动模式下每位用户都能在自己一侧选择语言、按住说话和理解当前活动状态。
- [ ] 屏幕旋转只影响视觉方向，不改变左说右听、右说左听的声道路由。
- [ ] 长文本和大字体可以完整阅读；小屏、系统栏与底部导航不会遮挡关键按钮。
- [ ] 错误、取消、页面离开及生命周期恢复不会留下错误的流式气泡或录音状态。
- [ ] 增加面对面布局、180°语义、触控目标和耳道目标的 Compose 或单元测试。
- [ ] Android 单元测试、相关 lint 与 Debug 构建通过。
