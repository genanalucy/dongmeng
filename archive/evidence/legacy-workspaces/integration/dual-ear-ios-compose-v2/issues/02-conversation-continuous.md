# 02: 完成对话 × 连续闭环

**What to build:** 在已落地的极简对话时间线上提供真实的连续双耳操作：左侧开始、暂停和继续持续收音；右侧按住临时接话，松开后恢复左侧。每次说话方转换都形成正确侧的流式气泡，并保留现有会话治理、配额、保存和终止行为。

**Blocked by:** 01: 落地对话 × 手动最小闭环.

**Status:** ready-for-agent

- [ ] 连续模式仍显示两个同层级圆形麦克风按钮，不退回单主按钮或小型接话胶囊。
- [ ] 左侧按钮可开始、暂停和继续持续收音；视觉状态明确但不依赖长说明文字。
- [ ] 右侧仅在连续收音期间支持按住临时接话，松开或取消后安全恢复左侧。
- [ ] 说话方转换时结束上一条当前气泡，并在正确侧创建下一条流式气泡；不重复、不串侧。
- [ ] UI 和无障碍文案不宣称自动检测或自动识别说话人。
- [ ] 会话终止、会话替换、配额阻断、页面离开及异常路径停止收音且不虚假显示保存或同步成功。
- [ ] 覆盖开始、暂停、继续、右侧接话、松开恢复、取消和错误恢复的状态转换测试。
- [ ] Android 单元测试、相关 lint 与 Debug 构建通过。
