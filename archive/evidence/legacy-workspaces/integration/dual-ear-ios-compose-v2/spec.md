# 双耳 iOS-inspired Compose v2

## 目标

将用户确认的离线原型重新实现为生产级 Android Compose UI。原型仅作为视觉与交互决策来源，不直接复制其 throwaway 实现。

## 已确认产品结构

- 两个视图模式：对话、面对面。
- 两种翻译模式：手动、连续。
- 共四个组合，均使用现有翻译、会话治理、历史保存及错误恢复能力。
- 对话按说话方左右错位；单个气泡内上方原文、分隔线、下方译文。
- 当前聆听、识别与翻译内容是时间线末尾的临时流式气泡；完成后在原位置转为历史气泡，不保留固定输入卡。
- 左右各一个完整圆形麦克风按钮，采用稳定、可区分的双色，并辅以位置、耳侧与语言语义。
- 连续模式固定左侧持续收音；右侧只能按住临时接话，松开恢复左侧。不得描述或表现为自动识别说话人。
- 一副耳机由两人各戴一只；手机麦克风收音；左侧说话的译音仅到右耳，右侧反向。

## 视觉方向

- 午夜蓝黑背景、大面积留白、克制的顶栏和胶囊底部导航。
- 历史气泡为低对比深灰；流式气泡通过侧色、轻描边、动态光标或波形区分。
- 左右麦克风使用原型确认后的雾蓝与暖砂方向；实际实现必须达到无障碍对比度，并且颜色不是唯一编码。
- 删除旧版常驻方向说明卡、固定语言输入气泡及冗余状态面板。

## 约束

- 不改后端协议、数据库或历史格式。
- 不清除 App 数据，不引入 Room migration。
- 不虚构耳机连接、云同步或保存状态。
- 保留面对面、同传、我的三个底部入口。
- Release 端点策略保持不变。
- Luna + high 负责实现；Sol + high 负责独立审查、测试和验收。
