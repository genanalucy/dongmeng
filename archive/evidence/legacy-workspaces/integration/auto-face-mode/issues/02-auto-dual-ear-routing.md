# 02: 自动模式单段双向路由

**What to build:** 当自动模式接受一段 A 或 B 语言发言时，产品自动建立相反方向的翻译 Turn，显示该实际方向的原文与译文，并只把目标语音送至使用目标语言的另一位参与者耳机；发言者自己的耳机绝不收到该 Turn 的译文。

**Blocked by:** 01 自动模式协议与方向契约.

**Status:** implemented

- [x] A→B 与 B→A 都由最终检测语言解析方向，并在最终字幕前完成路由。
- [x] 每个已接受 Turn 的 PCM 只经目标语言参与者的耳机路由播放，源语言说话者耳机没有该 Turn 音频。
- [x] 未解析方向前字幕、TTS 均被协调器抑制，已解析 Turn 继续使用既有有序播放机制。
- [x] 面对面协调器测试从检测方向断言可见 Turn 和播放路由，而非私有队列实现；TTS 仅在方向已解析后进入对侧耳机，发言者不会听到自身 Turn 的译文。
