# 面对面模式测试回归清单

Status: needs-triage

## 优先级与顺序

1. `01-far-side-mic-position`（高）：修正面对面视图远端说话按钮视觉上落在屏幕中线的问题。
2. `02-manual-release-playback-stall`（阻断发布）：诊断并修复手动松开说话键时正在播放的翻译出现约一秒卡顿、重播片段的问题。

## 已知边界

- 面对面翻译使用左右耳侧和相反物理播放路由；不能因为视觉位置调整改变路由。
- 手动按住/松开仅应管理采集回合，不能中断另一个已开始播放的翻译。
- 修复不得修改 Room schema、历史数据、云端 API 或 OTA 协议。

## 完成条件

- 两项问题都有可重复的自动化回归测试。
- 真机上连续执行“播放中按住另一侧说话 → 松开”不再出现可感知停顿或重复播放。
- 面对面上半区的远端说话按钮位于远端可触及的一侧，而不是双方面板中线。
