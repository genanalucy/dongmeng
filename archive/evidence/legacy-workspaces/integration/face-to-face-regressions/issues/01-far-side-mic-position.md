# 修复面对面远端麦克风位置

Type: bug
Status: ready-for-agent
Priority: high

## 现象

面对面视图中，远端（上半区）“按住说话”按钮显示在上下两块面板的中间附近。远端用户站在手机另一侧时，按钮不在其阅读区的外沿/底部，视觉和触控归属不清。

## 预期

远端面板的麦克风控制应属于远端面板、保持 180° 呈现，并放在远端用户可自然触及的一端；近端控制仍属于近端面板。位置调整不得改变左右语言、单侧采集、播放路由或语义标签。

## 验收

- Compose UI 测试断言远端麦克风控制边界位于远端面板而非中线区域。
- 远端文字与控制保持 180° 方向，近端保持正向。
- 手动与连续模式均只展示对应半区的单侧控制。
- 小屏、刘海/系统栏和大字体下不重叠、不裁切。
- 真机从双侧观察均可确认各自按钮处于本侧面板。
