# 实现高亮遮罩与无障碍语义

Type: task
Status: ready-for-agent
Blocked by: 01

## Goal

实现可主题适配的引导遮罩、真实控件高亮、说明卡和步骤控制，并确保语义树可以读出当前步骤、进度和目标操作。

## Acceptance Criteria

- 通过语义目标或注册边界定位，不使用固定屏幕坐标。
- 支持上一页、下一页、跳过和完成。
- 遮罩不允许误触底层业务控件。
- 浅色/深色主题、窄屏和大字体下说明与目标均可见。
- 提供当前步骤、总步骤和目标动作的无障碍语义。
- 缺失目标时安全跳过，不阻塞启动。
