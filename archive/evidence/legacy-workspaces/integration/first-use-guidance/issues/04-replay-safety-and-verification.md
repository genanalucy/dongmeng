# 增加重看入口并完成验收

Type: task
Status: ready-for-agent
Blocked by: 03

## Goal

在稳定入口提供“使用指南”重看能力，并验证首次、跳过、完成、离线、主题、无障碍和活动会话期间的安全行为。

## Acceptance Criteria

- 关于或帮助页可主动重新查看指南。
- 录音、播放、同传或面对面活动会话中不自动弹出；主动开启时安全延后或提示先结束操作。
- Compose/UI 测试覆盖步骤顺序、语义、高亮目标和跳过/完成。
- 单元测试覆盖缺失目标和活动会话保护。
- 真机验收覆盖首次安装、跳过、完成、重看、浅深色、无网络、已登录/未登录。
- 不引入用户文本、语音或账户标识埋点。
