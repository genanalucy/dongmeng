# 接入核心功能引导步骤

Type: task
Status: ready-for-agent
Blocked by: 02

## Goal

将首次指南接入真实产品壳和核心页面，按步骤说明对话、语言选择、按住说话、同传、面对面、我的与历史的使用方式。

## Acceptance Criteria

- 步骤仅高亮当前构建真实存在且可操作的控件。
- 覆盖三项底部导航和常用入口。
- 对话步骤说明语言选择与按住说话。
- 同传步骤说明语言配置、开始、暂停和结束。
- 面对面步骤说明左右语言、左右麦克风和单侧采集。
- 我的步骤说明账户、权益和历史入口。
- 引导不自动请求权限、不录音、不翻译、不播放、不创建历史记录、不改语言或账户状态。
- 测试版先启用；正式版通过产品开关控制。
