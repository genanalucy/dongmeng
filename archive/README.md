# 历史项目资料

此目录保留早期设计、实现计划、修复报告和验收记录。它们是项目知识，不作为现行安装、部署或功能验收结论。AI 工具的规则、技能、配置和提示词已删除，不在这里另存一套。

现行资料见[文档导航](../docs/README.md)，当前源码、PR 与安装包关系见[仓库状态](../docs/development/repository-status.md)。

## 分类

- [产品设计](documents/designs/)：账户、认证、Android 界面和内测设计，共 6 份。
- [实施计划](documents/implementation-plans/)：对应的 6 份历史计划，移除了绑定特定 AI 技能的调度要求。
- [实现与修复报告](documents/implementation-reports/)：原隐藏工具目录内的 20 份报告及 4 份账户中心报告。
- [历史验收资料](documents/reviews/)：6 份设计、来源清单和设备验收记录。
- [2026-08-26 项目交接](documents/2026-08-26-handoff.md)：当时的架构、协议、临时环境与未完成事项。
- [2026-11-04 开发基线](documents/2026-11-04-development-baseline.md)：旧分支、历史包哈希及标签/源码例外。
- [早期 Android 工程说明](documents/android-initial-guide.md)、[早期内测安装说明](documents/internal-beta-update-guide.md)。
- [Web/macOS 原型规格](documents/web-macos-translation-app-spec.md)：保留产品和音频协议知识，去掉面向编码代理的措辞。

共 47 份项目资料移入本目录；另外两份原根目录对话测试文案现位于[测试材料](../docs/testing/README.md)。逐文件来源见[迁移索引](source-index.md)。

历史正文中的命令、绝对路径和“当前”是当时的记录。保留这些文字便于追溯；实际 Markdown 导航已调整到新位置。
